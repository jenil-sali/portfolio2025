# 🚀 Jenil Sali — Software Developer Portfolio

Welcome to the repository for my personal software developer portfolio, redesigned for the AI-era (2026). This portfolio is engineered to be highly performant, visually premium, and immediately communicates my identity as a backend-focused full-stack developer.

🔗 **Live URL:** [https://jenilsali.netlify.app/](https://jenilsali.netlify.app/)

## ✨ Key Features
- **AI-Era Aesthetic:** A "dark-first" UI featuring a deep charcoal background (`#070A0F`) with cyan and violet glowing accents.
- **Interactive System Visual:** A simulated developer console that reinforces a technical identity upon landing.
- **Dynamic Animations:** Scroll-reveals, hover-lifts, and glowing node micro-interactions powered by Framer Motion.
- **Terminal CLI Contact:** A unique `/contact-jenil.sh` command-line style interface for sending messages (integrated with EmailJS & Telegram).
- **SEO Optimized:** Fully configured with meta tags, OpenGraph data, `robots.txt`, and `sitemap.xml` for maximum discoverability.

## 🛠️ Tech Stack
- **Framework:** React 19
- **Styling:** Vanilla CSS (CSS Variables, Flexbox/Grid, Glassmorphism)
- **Animations:** Framer Motion
- **Icons:** Lucide React & FontAwesome
- **Form Handling:** EmailJS API & Telegram Bot API

## 💻 Local Development

To run this project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jenil-sali/portfolio2025.git
   ```
2. **Install dependencies:**
   ```bash
   cd portfolio2025
   npm install
   ```
3. **Environment Variables:**
   Create a `.env` file in the root directory and configure the following variables for the contact form:
   ```env
   REACT_APP_TELEGRAM_URL="your-telegram-webhook-url"
   REACT_APP_TELEGRAM_CHATID="your-chat-id"
   REACT_APP_EMAILJS_SERVICEID="your-service-id"
   REACT_APP_EMAILJS_TEMPLETID="your-template-id"
   REACT_APP_EMAILJS_PUBLIC_KEY="your-public-key"
   REACT_APP_DEBUG=true
   ```
4. **Start the development server:**
   ```bash
   npm start
   ```
5. **Build for production:**
   ```bash
   npm run build
   ```
